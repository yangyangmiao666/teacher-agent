# 教智星教学智能体建设说明书

状态：待学校审核草稿。演示与真实课堂成效分开说明。

## 一、设计思路与技术路线

教智星面向高校专业课教师，覆盖课前备课、课堂实施辅助、课后评价与实验实训。以“教师主导、智能辅助、产物可编辑、证据可追溯”为原则，把重复性的资料整理、初稿编制、命题与反馈工作交给智能体，教师负责教学目标、内容准确性及最终成绩审定。

技术路线为 React Web 教学工作台、HTTP/WebSocket 服务、既有 Agent 会话运行时、七类教学技能和课程工作区。每个教学子台包含结构化编辑器与独立智能体对话，复用附件、模型选择、流式输出与会话历史。智能体输出可经教师确认应用到编辑器并撤销。浏览器草稿按工作区身份分区保存；智能体生成文件由工作区文件系统持有，二者不冒充同一份已发布教学资源。会话运行、任务排队及恢复仍由既有运行时负责。

公网试用采用阿里云单机 Docker 部署路径；服务端以限时共享口令保护 API 和 WebSocket，到期拒绝新请求并断开既有连接。口令持有者拥有容器内 Agent、文件与终端能力，因此仅向受信评审开放，不作为多租户公开教学平台。容器只挂载脱敏演示课程，不接校内生产系统。

## 二、建设过程与实现功能

本次在现有开源 Agent 及已存在的教学改造基础上，先更新产品规格，再核查教学工作台、技能与数据边界，完成自有源码品牌命名迁移，补充测试登录、服务端有效期控制、Web 运行目录构建、部署配置与申报证据整理。源码中的品牌标识同步更新所有引用，许可证与第三方版权保留。

现有七个子台分别提供教案、课件提纲与讲稿、专业案例、题库组卷及细目表、作业建议分与反馈、知识点学情看板、实验实训指导书与量表。七类技能按场景提示词调用；模型生成需由部署者配置有效供应商。课件提纲可下载为含封面、目标、页面内容、互动与讲稿备注的可编辑 PowerPoint 初稿，长文本自动分页；不宣称无需教师加工即可完整授课。学情薄弱点可进入针对性组卷和再教学教案，建设佐证时间线可导出。浏览器草稿可下载 Markdown。

验证记录详见建设过程与验证文件：类型检查、Lint、品牌门禁、构建及鉴权测试有实测记录。模型生成、云上访问、实际课堂使用与学校审核须分别取得证据，不能以功能界面或模板替代。

## 三、课堂教学应用场景及拟解决问题

以虚构演示课程《材料加工冶金与传输原理》为例，课前根据课程大纲与知识点 K02“对流传热与努塞尔数”生成教案初稿、课件提纲和工程案例讨论题，解决资料整理与备课初稿耗时问题。课中利用教学过程、互动问题和随堂练习组织讨论、答疑与形成性评价，教师核查公式、单位和适用条件后使用。

课后依据双向细目表组卷；对学生匿名作业提供建议反馈，教师复核评分依据；根据知识点汇总统计发现凝固传热、加热炉热平衡等薄弱点，组织再教学和分层练习。实践环节生成实验步骤、安全须知、记录表与评价量表，减轻材料编制负担。

演示数据为虚构统计和别名样例，不是学校实际成绩。真实材料必须先在授权环境中完成身份替换、敏感业务信息删除及人工复核，再进入对话或文件上传。提示词中的脱敏要求并不等于自动识别和拦截全部隐私数据。

## 四、应用成效及推广价值

目前可核验的成效为工程交付与功能验证，尚无可声称的真实课堂教学效果或师生满意度数据。试点拟采集教案与组卷耗时、教师修改率、建议评分与人工评分一致性、知识点前后测表现和师生反馈，记录样本、时间、基线、原始证据及复核人，不编造改善百分比。

推广价值在于替换大纲与知识点即可适配不同专业，复用可编辑模板和教学技能，形成从学情诊断到再教学的工作流。未来院系推广需补充用户隔离、细粒度权限与授权数据对接。项目属于基于开源的教学场景二次开发，原创性证明限定自主设计与实现部分。原始材料和匿名材料分别提交教务管理部门审核盖章后，才用于材料审核与专家评审。
