# 技术路线图

![教智星技术路线](./技术路线图.svg)

下列 Mermaid 是可编辑源：

```mermaid
flowchart TB
  subgraph client [教师端]
    Browser[浏览器 Web]
  end
  subgraph platform [教智星平台]
    UI[教学工作台 UI]
    Server[HTTP_WS Server]
    Agent[教学 Agent Runtime]
    Skills[教学 Skills 包]
  end
  subgraph data [课程工作区]
    Syllabus[大纲与知识点]
    Analytics[脱敏学情]
    Outputs[教案试卷评阅等产出]
  end
  Browser --> UI --> Server --> Agent
  Agent --> Skills
  Agent --> Syllabus
  Agent --> Analytics
  Skills --> Outputs
```

## 说明

1. 交互层：Web 会话与文件预览。  
2. 智能层：教学人设 + Skills 路由。  
3. 数据层：工作区文件；演示数据脱敏。  
4. 部署层：Docker Compose + 访问令牌（见 `docs/deploy-aliyun.md`）。
