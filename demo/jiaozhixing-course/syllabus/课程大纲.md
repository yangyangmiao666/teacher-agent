# 课程大纲（脱敏演示）

- 课程名称：材料加工冶金与传输原理
- 适用专业：材料成型及控制工程 / 冶金工程 / 材料科学与工程（演示）
- 学分学时：3 学分 / 48 学时（理论 32 + 实验 16）
- 开课单位：演示学院（虚构）

## 课程目标

1. 掌握动量、热量、质量传递的基本定律与相似准则。
2. 能将传递原理用于加热炉、凝固、轧制等材料加工与冶金工况的量级估算。
3. 养成单位一致性检验、关联式适用范围判断与工程报告规范表达的习惯。
