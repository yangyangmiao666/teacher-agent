# 产出目录

教智星 Agent Skills 生成的文件写入本目录；教学工作台草稿层（浏览器 localStorage）可导出为 Markdown 后对照归档。

| 子目录 | 对应 Skill | 工作台子台 |
| --- | --- | --- |
| `lesson-plans/` | `lesson-plan` | 教案编辑器 |
| `courseware/` | `courseware-outline` | 课件提纲 |
| `cases/` | `case-mining` | 案例库 |
| `exams/` | `exam-paper` | 题库组卷 |
| `reviews/` | `homework-review` / `learning-analytics` | 作业评阅台 / 学情看板 |
| `lab/` | `lab-practicum` | 实训材料 |

默认课程语境：《材料加工冶金与传输原理》。输入学情或作业时仅使用 `analytics/` 下脱敏样例或同等脱敏数据。
