# 申报材料交付与证据规则

- 两套材料分别存于 `docs/submission` 和 `docs/submission-anonymous`，正文不超过 3000 个可见字符（比通常字数口径更严格），交付 ZIP 每套小于 50 MB。
- 原创声明限定自主改造部分，保留上游许可证、作者版权及第三方原件；未提供来源提交历史时，不伪造日期、作者、签名或原创比例。
- 技术路线图同时提供可直接查看的 SVG 和 Mermaid 源码。建设记录区分当前源码核验、自动测试记录、待真实试点采集的信息。
- 示例课程、成绩和反馈不充当真实教学成效证据。真实成效表须填样本、时间、口径、基线、结果、数据来源与复核人。未提供的字段标记“待采集”。
- 原始与匿名版都需要学校教务管理部门审核并盖章；占位模板不等于已审核证明。匿名版隐去个人信息并保留材料关联编号及必要审核真实性，匿名规则由学校确认。
- 打包工具生成文件大小和 SHA-256 清单，自动检查正文长度、敏感信息常见模式及模板缺口；自动扫描不能替代人工复核。学校盖章前输出标为“待审核草稿”。
