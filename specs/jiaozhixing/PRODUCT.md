# 教智星产品规格（Web MVP）

## 定位

教智星是面向高校专业课教师的教学智能体 Web 应用，覆盖课前准备、课堂实施辅助与课后评价，以 Agent + Skills + 课程工作区承接重复性事务，帮助教师把精力放回教学设计与师生交互。

## 角色与权限

| 角色 | 能力 | 限制 |
| --- | --- | --- |
| 专业课教师（主用户） | 对话驱动生成教案、课件提纲、案例、试卷、评阅反馈、学情分析、实训材料；读写当前工作区文件 | 演示环境仅绑定脱敏演示工作区 |
| 评审/访客（测试账号） | 同上，使用访问令牌登录 Web | 令牌有有效期；禁止接入真实校内库、企业库 |

## 场景与 Skills

| 阶段 | 场景 | Skill 名称 | 主要产出 |
| --- | --- | --- | --- |
| 课前 | 教案撰写 | `lesson-plan` | 教案 Markdown |
| 课前 | 课件制作辅助 | `courseware-outline` | 课件提纲与讲稿结构 |
| 课前 | 专业案例挖掘 | `case-mining` | 脱敏教学案例 |
| 课后 | 智能组卷 | `exam-paper` | 试卷 + 双向细目表 |
| 课后 | 作业辅助评阅 | `homework-review` | 评阅报告与反馈话术 |
| 课后 | 学情数据分析 | `learning-analytics` | 薄弱知识点报告 |
| 实践 | 实验/实训材料 | `lab-practicum` | 指导书 + 评分量表 |

课堂实施阶段：教师可在课中调用案例讲解、随堂练习提纲与答疑提纲（复用上述 Skills，不单独建课中模块）。

## 状态与接口所有者

- **会话与流式输出**：沿用现有 Server / Agent Runtime（唯一运行时所有者）。
- **教学产出文件**：写入当前 `workspacePath` 下约定目录（如 `outputs/`），由文件系统为事实源；UI 不另建教案库。
- **访问控制（演示）**：`JZX_SERVER_AUTH_TOKEN`（兼容读取 `ZCODE_SERVER_AUTH_TOKEN`）控制 Web API/WS。

## 脱敏规则

涉及学生、企业、校内平台数据时必须脱敏后再进入工作区或对话：

1. 姓名 → 化名（如「同学 A01」）或学号哈希前 6 位
2. 学号 → 仅保留后 4 位或完全替换为 `S-xxxx`
3. 成绩 → 区间化或班级统计，禁止导出可反推个人的明细对外分享稿
4. 企业/项目名 → 虚构名称（如「星河科技」）
5. 校内系统 URL、工号、手机号、邮箱 → 打码或删除
6. 演示数据包默认已脱敏；用户粘贴疑似真实数据时，Agent 应提示先脱敏

## 产品级教学 UI

独立主视图「教学工作台」（`teaching-workbench`）提供七子台：教案、课件、案例、组卷、评阅、学情、实训；学情薄弱点可联动组卷与 Agent。领域草稿由 `teachingWorkbenchStore` 按工作区身份持久化。详见 [TEACHING_UI.md](./TEACHING_UI.md)。

模型配置不展示体验 / 个人 / 团队套餐，仅保留自定义供应商。详见 [NO_MODEL_PLANS.md](./NO_MODEL_PLANS.md)。

## 验收场景

1. Web 打开后标题与欢迎文案为「教智星」，无用户可见的原上游产品名。
2. 在演示工作区中，教师可用自然语言触发七类 Skills，并在 `outputs/` 得到对应文件。
3. 学情分析仅接受脱敏统计输入，报告中不出现真实姓名/学号。
4. 按 `deploy/` 文档可在本机 Docker 起服务；访问说明含 URL、令牌、权限与有效期。
5. `docs/submission/` 含 ≤3000 字建设说明书与原始/匿名佐证材料包。

## 申报与过程证据

教学工作台提供学情→再教学/组卷闭环、OBE 对齐清单与「建设佐证」时间线导出，便于 5 分钟评审演示与材料归档。演示数据坚持脱敏；智能体产出须经教师审定后使用。
