# 版本控制边界

只将源码、测试代码/夹具、共享开发配置、文档与申报材料源文件、技能资源、许可证及构建必需的固定第三方依赖纳入 Git。

忽略构建产物、下载/包管理缓存、测试运行输出、临时文件、日志、本地数据库与运行目录、Python 虚拟环境、本地环境变量和部署密钥。环境变量模板（`.env.example`、`.env.*.example`、`.env.template`）保留；不泛化忽略 PDF/图片/压缩包/声明文件，因为它们也可能是必需源资产。

当前演示课程 `outputs` 为智能体生成区，仅保留目录说明；申报说明书 PDF 和打包清单可由既有脚本重新生成，源 Markdown、技术路线 SVG 与应用证据截图保留。CLI 的源目录 JS 编译副本以及 Desktop 两组误写入源码目录的编译副本不纳入 Git。

Git 索引是版本控制的唯一所有者：更新 ignore 后，只将实际命中新规则的已跟踪文件移出索引；不执行全仓重新暂存，不删除本地文件，不更改其他文件的暂存状态。

验收：`git ls-files -ci --exclude-standard` 为空；缓存、私有配置、生成内容被忽略；源码、测试、模板、原生依赖、技能资源和人工声明仍可跟踪；移出索引前后的本地文件内容保持一致。
