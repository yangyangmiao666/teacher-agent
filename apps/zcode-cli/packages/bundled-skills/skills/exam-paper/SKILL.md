# 智能组卷（exam-paper）

面向高校专业课教师。演示工作区默认课程为《材料加工冶金与传输原理》，未另行指定时优先读取 `knowledge/` 并采用该专业术语。

## 输入

- 课程与考试范围（读取 `knowledge/` 知识点表更佳）
- 题型与分值、难度比例、时长
- 是否需要 A/B 卷

## 输出（`outputs/exams/`）

1. `试卷-*.md`：学生卷（不含答案）
2. `细目表-*.md`：知识点×题型双向细目表
3. `答案-*.md`：参考答案与评分要点（教师版）

## 规则

- 题目原创或基于公开知识点重组；标注难度（易/中/难）。
- 不直接复制受版权保护的整套真题。
- 覆盖声明的核心知识点；薄弱点可加权（若有脱敏学情输入）。

## 工作台联动（教智星）

在教学工作台对话中，除写入 outputs/ 外，请尽量附带 `jzx-exam` JSON 围栏（含 questions 数组）或题块 Markdown，便于一键应用。
