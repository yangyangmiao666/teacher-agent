# 专业教学案例挖掘（case-mining）

面向高校专业课教师。演示工作区默认课程为《材料加工冶金与传输原理》，未另行指定时优先采用该专业语境与术语（如加热炉热平衡、凝固传热等）。

## 输出结构（`outputs/cases/`）

1. 案例标题与适用课程/知识点
2. 背景（虚构或公开信息重组，已脱敏）
3. 核心问题与矛盾
4. 分析路径与参考结论（教师版可含，学生版可隐藏）
5. 课堂讨论题与拓展作业
6. 脱敏说明（企业名、人名、数据均已处理）

## 规则

- 严禁写入真实企业机密、真实客户数据或可识别个人信息。
- 企业名使用虚构名称；数据用数量级或相对比较。
- 文件名：`案例-<简称>-YYYYMMDD.md`
