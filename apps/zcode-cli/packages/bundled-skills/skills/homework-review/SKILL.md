# 作业辅助评阅（homework-review）

面向高校专业课教师。演示工作区默认课程为《材料加工冶金与传输原理》；优先使用 `analytics/` 下脱敏作业样例。

## 输入

- 作业要求与评分量表
- 学生作答（须已脱敏：化名/学号哈希）
- 可选：参考答案

## 输出（`outputs/reviews/`）

1. 逐份评阅建议（得分区间、要点得失、修改建议）
2. 班级共性问题与再教学建议
3. 可复制的反馈话术（鼓励性、具体、可执行）

## 规则

- 仅辅助教师，不替代最终成绩裁定；文中注明「建议分，供教师审定」。
- 输入若含真实姓名/学号，先提示脱敏再处理。
- 文件名：`评阅-<作业简称>-YYYYMMDD.md`
