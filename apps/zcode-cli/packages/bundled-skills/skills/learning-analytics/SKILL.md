# 学情数据分析（learning-analytics）

面向高校专业课教师。演示工作区默认课程为《材料加工冶金与传输原理》；优先读取 `analytics/` 脱敏统计并对照 `knowledge/` 知识点表。

## 输入

- 优先读取 `analytics/` 下脱敏统计（如知识点得分率、题型正确率）
- 禁止要求教师粘贴含真实身份的原始成绩册对外分享稿

## 输出

1. 总体概况（样本说明：已脱敏）
2. 薄弱知识点排序与证据
3. 可能原因假设（概念/技能/审题等）
4. 针对性再教学建议与练习设计
5. 可选：下次测评关注点

## 规则

- 报告中只使用化名或聚合指标。
- 不做无法由数据支持的个体标签化断言。
- 文件名：`学情分析-<课程简称>-YYYYMMDD.md`

## 工作台联动（教智星）

在教学工作台对话中，请输出可解析的薄弱点表格，并尽量附带 `jzx-analytics` JSON 围栏；建议给出「再教学教案 + 针对性组卷」闭环动作。
