# 教案撰写（lesson-plan）

面向高校专业课教师。根据课程大纲、知识点表与教师意图，生成可直接用于备课的教案。演示工作区默认课程为《材料加工冶金与传输原理》，未另行指定时优先采用该专业语境与术语。

## 输入

- 课程名称、专业、学时、授课对象
- 本节课题 / 对应知识点（可读取 `syllabus/`、`knowledge/`）
- 可选：已有教学风格、思政要求、实验条件

## 输出结构（写入 `outputs/lesson-plans/`）

1. 基本信息（课程、课题、学时、授课对象）
2. 教学目标（知识 / 能力 / 素养）
3. 教学重难点
4. 教学方法与资源
5. 教学过程（导入→讲授→练习→小结，含时间建议）
6. 思政融入点（自然融入，避免生硬）
7. 板书 / 演示要点
8. 课后任务与评价方式

## 规则

- 使用简体中文；专业术语准确。
- 不编造未提供的学情个人数据；需要学情时引用脱敏统计。
- 文件名：`教案-<课题简称>-YYYYMMDD.md`

## 工作台联动（教智星）

若教师在「教学工作台」对话中请求生成/完善教案，除写入 `outputs/lesson-plans/` 外，请在回复正文使用与编辑器一致的二级标题，并尽量附带 JSON 围栏便于一键应用：

```jzx-lesson
{
  "title": "课题",
  "objectives": "...",
  "outcomeAlignment": [
    { "id": "co1", "code": "CO1", "statement": "课程目标表述", "covered": true }
  ]
}
```
