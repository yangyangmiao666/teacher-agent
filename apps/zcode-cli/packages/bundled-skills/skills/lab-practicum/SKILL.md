# 实验实训材料（lab-practicum）

面向高校专业课教师。演示工作区默认课程为《材料加工冶金与传输原理》，未另行指定时可生成圆管强制对流换热等传输类实验指导书。

## 输出（`outputs/lab/`）

1. 实训/实验指导书（目的、原理摘要、器材、步骤、注意事项）
2. 安全与合规提示
3. 数据记录表（可打印 Markdown 表）
4. 评分量表（过程/结果/报告权重）
5. 可选：常见故障与排错

## 规则

- 步骤可执行、风险提示明确；不假设危险操作无防护。
- 企业实训场景使用虚构单位与脱敏数据。
- 文件名：`实训-<简称>-YYYYMMDD.md`
